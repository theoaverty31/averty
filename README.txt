PORTFOLIO THÉO — DÉMARRAGE

Fichiers :
- index.html : contenu et structure
- style.css : identité visuelle et responsive
- script.js : menu mobile et animations
- assets/ : place tes images ici

IMAGES
Crée un dossier assets et ajoute tes visuels en reprenant les noms indiqués dans le HTML :
portrait.jpg, about.jpg, asso-1.jpg, asso-2.jpg, asso-3.jpg,
creation-1.jpg à creation-4.jpg, photo-1.jpg à photo-6.jpg.
Les cadres de remplacement s'affichent si certaines images manquent.
Tu peux modifier les textes directement dans index.html.

PUBLIER SUR GITHUB PAGES
1. Crée un dépôt GitHub, par exemple theo-portfolio.
2. Ajoute index.html, style.css, script.js et le dossier assets.
3. Dans Settings > Pages, choisis Deploy from a branch, puis main et /(root).
4. Enregistre : GitHub affichera l'adresse publique du site.

Les liens de navigation et le mail sont déjà fonctionnels. Pense à remplacer le lien LinkedIn générique par ton profil.
